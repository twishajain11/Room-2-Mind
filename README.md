# Room to Mind

Measures the attention load of a physical space across a visual and an acoustic channel, entirely in the browser.

The full README required by the spec (six headings, Section 10) is a Week 4 deliverable and is deliberately not half-written here. The source of truth for the build is `PRODUCT_SPEC.md`.

## Running it

```
npm install
npm run dev      # http://localhost:5220
npm run test     # vision feature unit tests
npm run typecheck
```
